# Catalog refresh — 2026-10-09

The catalog and price book now contain 37 identities, up from 35. This update
combines targeted native verification with direct review of official provider
documentation. It is not a completed automated sweep of every bundled record.

## Added models

Claude Haiku 5.5 is added for Anthropic and Vertex, with a 1,000,000-token context
window, 128,000-token output limit, and October 7 release date. The sources give
only a month for its knowledge cutoff and an earliest possible retirement date;
neither is converted into an exact date in the catalog.

Standard USD rates per million tokens:

| Prompt length | Input | Output | Cache read | Five-minute cache write |
| --- | ---: | ---: | ---: | ---: |
| Up to 100,000 tokens | 0.10 | 0.50 | 0.01 | 0.125 |
| Above 100,000 tokens | 0.50 | 2.50 | 0.05 | 0.625 |

The context threshold counts the entire prompt, including cache reads and
writes. Tier-local cache-write rates represent five-minute writes. Batch and
one-hour cache-write prices are omitted because the schema cannot express
their context-dependent rates. The Vertex pricing table labels the short band
as at most 100K, although its footnote says greater than or equal to 100K;
Google's supported-models page also specifies 100,000 or fewer for the short
band, matching Anthropic's explicit boundary.

Sources: [Anthropic model and pricing](https://platform.claude.com/docs/en/models/haiku-5-5/overview),
[migration and structured outputs](https://platform.claude.com/docs/en/models/haiku-5-5/migration-guide),
[Vertex model](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/partner-models/claude/haiku-5-5),
[Vertex pricing](https://cloud.google.com/gemini-enterprise-agent-platform/generative-ai/pricing),
[Vertex context-band boundary](https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/provisioned-throughput/supported-models).

## Corrections and verification

Claude Sonnet 5.5 Standard cached input is corrected from $0.20 to $0.10 per
million tokens for both Anthropic and Vertex. Vertex Batch cached input is
corrected from $0.10 to $0.05. Existing schedules remain available for historical
cost reconstruction; the corrected schedules start on the verification date.
Sources: [Anthropic pricing](https://platform.claude.com/docs/en/about-claude/pricing)
and the Vertex pricing table linked above.

Native verification using published Cayu 0.10.0 and its pinned browser completed
for nine Anthropic models and four OpenAI models (GPT-6 Astra, Sol, Luna, and
GPT-6.1 Sol). Eight Anthropic updates and all four OpenAI updates passed policy
validation. Haiku 4.5's proposed inferred Batch cache-read dimension was rejected,
so that record retains its earlier values and provenance. OpenAI's tiered Batch
prices remain omitted; their short-context rates must not be applied globally.

The [OpenAI model guide](https://developers.openai.com/api/docs/models) and
[Google model guide](https://ai.google.dev/gemini-api/docs/models) recommend
general-purpose models already present in the catalog. Media-specialized and
restricted-access models were not added by this update.

Azure checks were inconclusive. Bedrock and Google attempts encountered browser
limits and were interrupted; the complete recommendation sweep was not run.
An isolated Google reproduction identified the 10,000 DOM-node bound. These
records retain their earlier evidence dates. Vertex additions and corrections
above use direct official-source review rather than a completed native sweep.

Validation includes the 30-day freshness and identity-pairing gate and cost
checks at 100,000 and 100,001 prompt tokens, including cached reads and writes,
for both new provider identities.
